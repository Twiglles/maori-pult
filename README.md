# Māори · пульт проекта

Статичная версия пультов для GitHub Pages — только просмотр, данные вшиты в страницы.

- `/` — общий пульт проекта
- `/team/` — старая ссылка, переадресует на главную

## Как опубликовать

1. Загрузите содержимое этой папки в репозиторий на GitHub (в корень).
2. Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
3. Через минуту сайт будет по адресу `https://<логин>.github.io/<репозиторий>/`.

## Как обновить данные

Данные редактируются в пультах на claude.ai. Чтобы обновить сайт, попросите Claude
«обнови снимок и пересобери экспорт для GitHub», затем замените файлы в репозитории.
